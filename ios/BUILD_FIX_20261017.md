# Build fix - 2026-10-17

The supplied GitHub Actions log fails in PMSceneUI.mm because the scene state
variable `sceneimpl::open` collides with the POSIX `::open()` function brought
in by the iOS SDK. All seven state references now use `modEditorOpen` instead.
No gameplay logic was changed for this fix. The two deprecated UIKit API
warnings in PhiModBootstrap.mm were not the cause of the failed build.

Changed files:
- PhiMod/Sources/PMSceneUI.mm
- tests/test_source_contracts.py
- tests/test_scene_state_lookup.py (new)
- tests/run_core_tests.sh

A host C++ compiler regression extracts the actual scene state declaration,
reproduces the old ambiguity and compiles the fixed spelling. The CI portable
test step now runs this regression. Source guards and the existing core,
judge/gateway and dump contract tests also passed locally. This is NOT a full
Apple SDK build or iPad validation; rerun CI on the NEW commit to verify those
compile errors are resolved. Re-running the old workflow run uses old code.

For the smallest fix, replace `ios/PhiMod/Sources/PMSceneUI.mm` in your repository.
Uploading this bundle's complete `ios` directory also installs the regressions.
There is no need to modify signing, Xcode version, hook addresses or game data.
